# 화면 정의서

| Depth 1 · 주요 영역 | 화면 ID | 화면명 | 유형 | 화면 목적 및 핵심 기능 |
|---|---|---|---|---|
| 홈 | HM-001 | 홈 | Page | 내 조건에 맞는 공고를 부합도 높은 순으로 바로 제시 |
| 홈 | HM-002 | 내 조건 요약 | Section | 조건이 비면 부합도 계산 불가 → 조건 입력 유도 |
| 알바 탐색 | EX-001 | 알바 찾기 | Page | 직종·지역 검색 + 시급·요일·시간대 필터 |
| 알바 탐색 | EX-002 | 공고 목록 | Page | 카드마다 부합도(%)·필수 자격 O/X 노출, 안 열어보고 거르기 |
| 조건 부합 확인 | FT-001 | 공고 상세 | Page | 급여·근무 시간·위치·모집 요건 확인 후 지원 진입 |
| 조건 부합 확인 | FT-002 | 내 조건 부합도 | Section | 내 희망 조건과 공고 조건의 일치율 %로 표시 |
| 조건 부합 확인 | FT-003 | 필수 자격 확인 | Section | 나이·경력·자격증·가능 시간 충족 여부 O/X |
| 조건 부합 확인 | FT-004 | 부합도 자세히 보기 | Bottom Sheet | 항목별 맞음/어긋남 근거로 % 수치를 믿게 함 |
| 지원 | AP-001 | 지원 내용 확인 | Page | 기본 이력서 그대로 지원 정보 최종 확인 후 제출 |
| 지원 | AP-002 | 지원 완료 | Page | 지원 접수 알림 + 조건 비슷한 다음 공고 연결 |
| 내 조건 | MY-001 | 내 근무 조건 | Page | 시급·요일·시간대·거리·직종 등 부합도 계산 기준값 등록 |
| 내 조건 | MY-002 | 경력 및 자격 | Page | 필수 O/X 판정에 쓰이는 경력·자격증·가능 시간 입력 |
| 내 조건 | MY-003 | 내 이력서 | Page | 지원에 쓸 기본 이력서 확인·선택 (수정은 MVP2) |
