# UX Writing 가이드라인

## 대표 묘사 문장

> "알바 지원에 확신을 심어주는 구직 가이드"

### 브랜드 페르소나

| 항목 | 내용 |
|---|---|
| 핵심가치 · 지향점 | 모든 일과 일하는 사람을 존중하고, 이제 막 시작하는 이들 곁에서 솔직하고 다정하게 응원하는 든든한 목소리 |
| | 친근하지만 가볍지 않고 신뢰를 잃지 않게 소통 |

## 보이스

- 쉽고 정직하게 말하되, 지원하는 사람 곁을 든든하게 지키는 목소리

## 톤

- **검색 결과가 없을 때**
  조건에 딱 맞는 알바를 찾지 못했어요. 필터를 바꿔서 더 많은 알바를 확인해 보세요.
- **지원 완료시**
  총 1건 지원 완료했습니다.
- **지원 가능한 알바 추천**
  함께 지원 가능한 알바가 5개 있어요!

## 톤 매트릭스

| 상황 | 재미 ↔ 진지 | 격식 ↔ 캐주얼 |
|---|---|---|
| 온보딩/내 조건 등록 | 진지 (60%) | 캐주얼 (35%) |
| 부합 근거 확인/지원 결정 | 진지 (90%) | 캐주얼 (55%) |
| 검색 결과 없음/에러 | 진지 (100%) | 캐주얼 (70%) |

## UI 요소별 가이드라인

### CTA 버튼

- `<지원>`에 틀이 맞춰져 있음
  "지원하기", "총 1건 지원 완료하기"

### 에러 메시지

- 문제 해결 방안 제시
  조건에 딱 맞는 알바를 찾지 못했어요. 필터를 바꿔서 더 많은 알바를 확인해 보세요.
  사전 질문 답안을 입력해 주세요.
