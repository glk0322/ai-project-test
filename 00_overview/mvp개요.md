# MVP 실행 범위와 성과 지표(KPI)

## Business Goal · 왜 만들어야 하는지

### 개요

*(원문 일부 글자가 겹쳐 있어 판독 불가)*
사용자의 이력과 공고 부합도를 알기 쉽게 한다

**목표**
- 지원 이탈률 감소
- 공고 탐색 시간 감소
- 스크랩"만" 하는 공고 횟수 감소

### MVP 실행범위 및 KPI

**MVP:** *(원문 일부 글자가 겹쳐 있어 판독 불가)*, 내 조건 부합도 표시 (%), 필수 자격 불만족/만족 표시 (O/X)

**핵심 검증:** 지원 부담과 불확실성을 확연하게 줄이는가

**KPI:** 지원 전환률 / 탐색 시간

## Roadmap · MVP 단계별 범위

**Phase 1 (MVP)**
- 내 조건 부합도 표시 (%)
- 필수 자격 불만족/만족 표시 (O/X)

## Core 문제 → KPI 흐름

| 구분 | 내용 |
|---|---|
| Core 문제 | 부합률 판단 어려움 |
| 아이디어 | 부합률 계산 및 표시 |
| User Flow | 내 조건 설정(시간·거리·요일) → 목록에 부합률·지원가능 배지 표시 → 부합 공고만 열람 → 지원 |
| 비즈니스 임팩트 | 탐색 시간 ↓ · 부적합 공고 열람 ↓ · 지원 전환 ↑ |
| KPI (성공 지표) | 공고 열람당 지원 전환율 ↑ · 부적합 공고 열람 비율 ↓ · 평균 탐색 시간 ↓ |
